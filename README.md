# ✋ Real-Time Hand Detection with handtrack.js

This project uses [handtrack.js](https://github.com/victordibia/handtrack.js) to perform real-time hand detection in the browser using the webcam and HTML5 `<canvas>`.

---

## 📸 Features

- Real-time hand tracking using webcam
- Draws bounding boxes for up to 3 hands
- Filters predictions based on confidence score
- Runs directly in the browser — no backend needed

---

## 🛠️ Technologies Used

- Vanilla JavaScript
- HTML5 `<video>` and `<canvas>`
- [handtrack.js](https://github.com/victordibia/handtrack.js)
- Web APIs (`getUserMedia`, `requestAnimationFrame`)
